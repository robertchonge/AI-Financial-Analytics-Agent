# 📊 AI Financial Analytics Agent

An AI-powered financial analysis tool that helps businesses understand their financial data faster.

The application allows users to upload financial statements in **CSV, Excel, or PDF formats** and automatically generates:

- 📈 Income and expense breakdowns
- ⚠️ Financial risk insights
- 💡 Actionable business recommendations
- 📊 Data summaries for better decision-making

The goal is to simplify financial analysis by combining modern web technologies with AI-powered insights.
